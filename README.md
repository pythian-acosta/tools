# Pythian Tools

A collection of internal utilities maintained by `pythian-acosta`, available via GitHub Pages at:

📍 **https://pythian-acosta.github.io/tools/**

## Available Tools

### 🔹 [Name Formatter](https://pythian-acosta.github.io/tools/name-formatter.html)
Convert a list of names into multiple output formats:
- Space-separated
- Pipe-separated
- `--tag name=...` formatted

Includes copy-to-clipboard functionality with visual feedback and input validation.
